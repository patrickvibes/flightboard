# Flight Board

Live aircraft overhead, on a tiny ESP32 + OLED board and in your browser.

This repository hosts the **Flight Board website, firmware releases and
changelog**. It's published automatically from the (private) source repo.

- Website & docs: https://patrickvibes.github.io/flightboard/
- Install or update from your browser: https://patrickvibes.github.io/flightboard/install/
- What's new: [CHANGELOG.md](CHANGELOG.md)
