c:Td0c,<h1 id="install-with-the-arduino-ide-advanced">Install with the Arduino IDE (advanced)</h1>
<blockquote>
<p><strong>Most people should use <a href="/flightboard/install/">Install from your browser</a></strong> — it's
one click and needs no software. This page is for building the firmware
yourself, e.g. if you want to change the code.</p>
</blockquote>
<p>This puts the Flight Board firmware on your ESP32 using the free Arduino IDE.
It takes about 20 minutes the first time, most of it downloads.</p>
<h2 id="1-install-the-arduino-ide">1. Install the Arduino IDE</h2>
<p>Download it from <a href="https://www.arduino.cc/en/software">arduino.cc/en/software</a>
and install it.</p>
<h2 id="2-add-esp32-support">2. Add ESP32 support</h2>
<ol>
<li>Open <strong>Settings / Preferences</strong>.</li>
<li>In <strong>Additional boards manager URLs</strong>, add exactly one line:
<pre><code>https://espressif.github.io/arduino-esp32/package_esp32_index.json
</code></pre>
Don't list it twice — duplicate URLs make the install fail.</li>
<li>Open <strong>Tools → Board → Boards Manager</strong>, search <strong>esp32</strong> (by Espressif
Systems) and click <strong>Install</strong>. If it fails, remove it, restart the IDE and
install once more.</li>
</ol>
<h2 id="3-install-the-libraries">3. Install the libraries</h2>
<p><strong>Tools → Manage Libraries</strong>, then install:</p>
<ul>
<li><strong>Adafruit SSD1306</strong> (accept the prompt to install Adafruit GFX too)</li>
<li><strong>ArduinoJson</strong> by Benoit Blanchon — version 7 (tested with 7.4.3)</li>
<li><strong>WiFiManager</strong> by tzapu (tested with 2.0.17)</li>
</ul>
<h2 id="4-open-the-sketch">4. Open the sketch</h2>
<p>Download the project folder (on GitHub: <strong>Code → Download ZIP</strong>) and unzip it.
The folder must be called <code>esp32_flight_tracker</code>, matching
<code>esp32_flight_tracker.ino</code> inside it. Open that <code>.ino</code> in the Arduino IDE;
the other code files open automatically as tabs.</p>
<h2 id="5-board-settings">5. Board settings</h2>
<p>In the <strong>Tools</strong> menu set:</p>
<table>
<thead>
<tr>
<th>Setting</th>
<th>Value</th>
</tr>
</thead>
<tbody>
<tr>
<td>Board</td>
<td><strong>ESP32 Dev Module</strong></td>
</tr>
<tr>
<td>Partition Scheme</td>
<td><strong>Huge APP (3MB No OTA/1MB SPIFFS)</strong></td>
</tr>
<tr>
<td>Upload Speed</td>
<td><strong>115200</strong></td>
</tr>
<tr>
<td>Port</td>
<td>your board (see below)</td>
</tr>
</tbody>
</table>
<blockquote>
<p>The partition scheme will change when over-the-air updates arrive.</p>
</blockquote>
<h2 id="6-connect-and-upload">6. Connect and upload</h2>
<ol>
<li>Plug the board <strong>directly</strong> into your computer with a <strong>data</strong> cable.
Avoid USB hubs — some won't detect the board.</li>
<li>Choose the new port under <strong>Tools → Port</strong> (on a Mac it looks like
<code>/dev/cu.usbserial-…</code> or <code>/dev/cu.wchusbserial-…</code>).</li>
<li>Click <strong>Upload</strong> (→). When it says <em>Done uploading</em>, the board restarts and
shows its boot animation.</li>
</ol>
<p>If the port never appears or the upload fails, see
<a href="/flightboard/troubleshooting/#flashing">Troubleshooting</a>.</p>
